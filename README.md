## About the Project

The Machine Ordering System is a business application built using **Microsoft Power Apps Canvas Apps** within the Microsoft Power Platform for a Melbourne-based café business.

The application provides a visual interface for browsing coffee machines, exploring product categories, and viewing product prices. It is designed to make product discovery easier through an intuitive, catalogue-style experience.

## Business Context

Coffee businesses need an accessible way to present their equipment offerings to customers. A well-organised product catalogue helps users explore available machines and compare options based on product type and price.

This project demonstrates how a low-code application can support a business's product browsing and machine ordering processes through a customised user interface.

## Problem Statement

A product catalogue can become difficult to navigate when products are not organised clearly or when customers have limited visibility of product information.

The goal of this project was to create a centralised, user-friendly interface that organises coffee machines into relevant categories and presents product information consistently.

## Project Objectives

- Develop a user-friendly machine ordering interface using Power Apps.
- Organise coffee machines into clearly defined product categories.
- Display product images, names, and prices in a consistent layout.
- Improve product discoverability through visual navigation.
- Demonstrate the practical application of low-code development within Microsoft Power Platform.

## Application Components

### 1. Product Catalogue

Displays coffee machines in a structured grid layout, with product images, names, and prices to support product browsing and comparison.

### 2. Category Navigation

Provides visual navigation through four product categories:

- At Home Coffee Makers
- At Home Espresso Machines
- Commercial Coffee Makers
- Commercial Espresso Machines

### 3. Product Display

Presents product information using image-based product cards and consistent pricing labels, creating a clear and accessible browsing experience.

### 4. Navigation Controls

Provides on-screen navigation to support browsing through the available product catalogue.

## Key Features

- **Visual product catalogue:** Browse coffee machines through product images and structured product cards.
- **Category-based navigation:** Explore machines by home or commercial use and coffee-making type.
- **Product information display:** View product names and prices directly in the catalogue.
- **Consistent interface design:** Use a clean layout with visual category panels and clearly presented product information.
- **Low-code development:** Build a tailored business interface using Microsoft Power Apps.

## Business Impact

The application demonstrates how Microsoft Power Apps can be used to create a customised business interface for presenting products and supporting ordering-related workflows.

Key benefits of the design include:

- Improved organisation of the product catalogue.
- Easier navigation between machine categories.
- Clearer presentation of product information and pricing.
- A foundation for extending the application with order management and business process automation.

## Future Improvements

Potential enhancements to extend the application include:

- **Order management:** Add a shopping cart and order submission functionality.
- **Data integration:** Connect Microsoft Dataverse or another supported data source to manage products and orders.
- **Inventory management:** Display stock availability and product status.
- **Workflow automation:** Use Power Automate for order notifications and approval workflows.
- **Business intelligence:** Integrate Power BI to analyse product demand, ordering trends, and sales performance.

## Key Takeaways

This project demonstrates practical experience in designing a business application with Microsoft Power Apps Canvas Apps. It highlights low-code development, user interface design, product categorisation, and the potential to extend a simple catalogue into a broader business solution using Microsoft Power Platform.
